# 시그널그룹 지역별 당근 광고

하나의 프로젝트에서 공용 디자인과 접수 스크립트를 사용하고, 지역별 하위 경로로 광고 URL을 분리합니다.

## 지역별 경로

- `/all/` — 전국
- `/wj/` — 강원 원주
- `/cc/` — 강원 춘천
- `/ic/` — 경기 이천
- `/yj/` — 경기 여주
- `/sn/` — 경기 성남

각 페이지는 경로를 기준으로 지역을 자동 판별하며, 신청 데이터의 `region` 값과 캠페인 코드에 해당 지역을 기록합니다. 전국 페이지는 화면에서 특정 지역을 노출하지 않고 접수 데이터에 `전국`을 기록합니다.

## 접수 연결

신청 폼은 기존 광고에서 사용 중인 Google Apps Script 웹 앱으로 전송됩니다. 주요 전송 항목은 이름, 연락처, 지역, 광고 채널, 캠페인 코드, 접속 URL입니다.

## 광고 기준

- DB 제공량: 월 20건 지원
- 운영 브랜드: (주)시그널그룹
- 기본 유입 채널: 당근
