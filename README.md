# 시그널그룹 시니어케어 전문 컨설턴트 공개채용

하나의 프로젝트에서 공용 디자인과 접수 스크립트를 사용하고, 전국 및 지역별 하위 경로로 공개채용 상담 URL을 분리합니다. 상단 탭과 각 섹션의 CTA를 통해 업무·활동·교육·보상 안내와 15분 상담 신청으로 이동합니다.

## 지역별 경로

- `/all/` — 전국
- `/wj/` — 강원 원주
- `/cc/` — 강원 춘천
- `/ic/` — 경기 이천
- `/yj/` — 경기 여주
- `/sn/` — 경기 성남

각 페이지는 경로를 기준으로 지역을 자동 판별하며, 신청 데이터의 `region` 값과 캠페인 코드에 해당 지역을 기록합니다. 전국 페이지는 화면에서 특정 지역을 노출하지 않고 접수 데이터에 `전국`을 기록합니다.

## 고객접수 페이지

- `/care/` — 초고령화 시대 돌봄비 준비 무료자료 신청

고객접수 페이지는 `region`, `source`, `campaign` URL 값을 읽어 기존 Google Apps Script에 상담 신청으로 기록하고, 신청 완료 후 고객 안내 PDF를 내려받습니다. 예: `/care/?region=wonju&source=daangn&campaign=care-guide`

## 접수 연결

신청 폼은 배진우 개인 전용 Google Apps Script 웹 앱으로 전송됩니다. 주요 전송 항목은 이름, 연락처, 지역, 광고 채널, 캠페인 코드, 접속 URL이며 배진우 이메일과 텔레그램, 구글 시트로 전달됩니다.
